# Hidrógeno muónico y el radio del protón

Buen día. Estos códigos fueron hechos para la versión **R2016a** de MATLAB, ya que es con la que se cuenta.

## Cómo correrlos

1. Ten en una misma carpeta las dos carpetas llamadas `matlab` y `datos`.
2. Abre MATLAB, da clic en **Open** y abre el archivo `ejecutar_todo.m`, que está dentro de la carpeta `matlab`.
3. Da clic en **Run** (o presiona **F5**). Si MATLAB pregunta si quieres cambiar la carpeta actual, elige **Change Folder**.

El archivo `ejecutar_todo.m` corre en automático cada uno de los códigos (`s1` a `s7`). Al terminar, las figuras quedan en la carpeta `figuras` y las tablas y resultados en la carpeta `resultados`; ambas se crean solas junto a `matlab` y `datos`.
